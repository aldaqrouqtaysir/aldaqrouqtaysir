# Taysir Al Daqrouq

I'm a Computer Science student at United Arab Emirates University. I'm interested in AI research, AI engineering, machine learning, data science, software engineering, and research software.

I want the things I build to be useful to someone, not just technically interesting. I'm interested in both research and engineering because I want to understand how an approach works and turn it into software people can use.

## Selected work

- **[Dubai PM₂.₅ Cross-Site Forecasting](https://github.com/aldaqrouqtaysir/dubai-pm25-cross-site-forecasting):** A forecasting study testing how well models transfer across four Dubai sensor sites using leave-one-site-out evaluation and leakage controls.
- **[Inferential Safety Lab](https://github.com/aldaqrouqtaysir/inferential-safety-lab):** Statistical research software that uses deterministic simulations to compare analysis pipelines under missingness and measurement error.
- **[SAIS Academic Navigator](https://github.com/aldaqrouqtaysir/academic-pathfinder-app):** A rule-based academic planner that evaluates up to 1,728 schedules from a 57-course catalog.
